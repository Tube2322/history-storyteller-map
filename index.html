วางสคริปต์ฉากของคุณ แล้วกด "นำเข้าสคริปต์" เพื่อเริ่มดูตัวอย่าง

นำเข้าสคริปต์ซีน

🧭 สร้างฉากง่ายๆ (จากจุด A ไป B) — ไม่ต้องพิมพ์ tag เอง (กด "แก้ไข" ที่การ์ดฉากด้านล่างเพื่อแก้ฉากที่สร้างไว้ก่อนหน้าได้)
วิธีเขียนสคริปต์ + รายการ tag ทั้งหมด (แตะเพื่อดู)

ข้อกำหนดของสคริปต์ (อ่านก่อนพิมพ์):
• ต้องมี 3 อย่างเสมอ: place (ชื่อสถานที่) + cam (แผนกล้อง ต้องสะกดตรงตามรายการด้านล่าง) + script (บทพากย์) — ขาดอันใดอันหนึ่ง ฉากนั้นจะถูกข้ามเงียบๆ ไม่มีสถานที่ก็จบ (ไม่ error ให้เห็น ต้องเช็กเองว่าจำนวนฉากในเส้นเวลาตรงกับที่พิมพ์)
• ห้ามใช้ | ในเนื้อหา (ชื่อสถานที่/บทพากย์/ค่าใดๆ) เพราะ | คือตัวคั่น tag — ถ้าต้องแบ่งบทพากย์เป็นหลายช่วงให้ใช้ ;; แทน
• แต่ละบรรทัด = 1 ฉาก, คั่นแต่ละ tag ในบรรทัดด้วย |, ในหนึ่ง tag คั่นชื่อคีย์กับค่าด้วย =
• ชื่อคีย์ (เช่น place, cam) ใช้ได้เฉพาะตัวอักษรไทย/อังกฤษเท่านั้น ห้ามมีตัวเลข ขีด หรือช่องว่างปนในชื่อคีย์
• พิกัด (latlng, จุดใน arrows/warmorph/draw/geophoto) ต้องเป็น lat,lng คั่นด้วย , เท่านั้น เรียง lat ก่อน lng เสมอ
• พิมพ์เฉพาะคีย์ที่จำเป็นก็พอ ที่เหลือ default ให้อัตโนมัติ — คีย์ที่พิมพ์ผิด/ไม่มีในระบบจะถูกข้ามเงียบๆเช่นกัน (ไม่ error) ดังนั้นถ้าตั้งค่าแล้วไม่มีผล ให้เช็กตัวสะกดคีย์ก่อน
• แผนกล้อง/ไอคอน/เอฟเฟกต์ ต้องสะกดตรงกับรายการที่กำหนดไว้เป๊ะ (ตัวเล็กหมดทุกตัว) — สะกดผิดจะถูกใช้ค่า default แทนเงียบๆ

แบบ tag (ยืดหยุ่น เรียงลำดับไหนก็ได้ ไม่ใส่คีย์ไหนก็ default):
place=... | latlng=lat,lng | cam=... | script=... | sec=... | icon=... | effect=... | tilt=... | bearing=... | highlight=... | insert=...
ใส่แค่บางคีย์ก็ได้ เช่น place=สุโขทัย | cam=fly-to | script=... | tilt=40 | bearing=200

แบบ column เดิม (เรียงตำแหน่งตายตัว):
สถานที่ | lat,lng | แผนกล้อง | สคริปต์เสียง | วินาที | ไอคอน | เอฟเฟกต์ | insert

แผนกล้อง: establishing / fly-to / push-in / zoom-out / orbit / cut-to-insert / insert-overlay / battle-map
ไอคอน: city / castle / ship / battle / flag / mountain / camp (ไม่ใส่ = 📍)
เอฟเฟกต์: storm / fire / battle / none — สติ๊กเกอร์อนิเมชันปักบนพิกัด
tilt: 0-60 (องศาเอียงกล้อง 3D) · bearing: 0-360 (ทิศเริ่มช็อต ไม่หมุนต่อเนื่อง) — ใช้ได้เฉพาะ tag-mode
highlight: country / province / place / none — ไฮไลต์เขตแดนจริงจาก OpenStreetMap ตามพิกัด พร้อมป้ายชื่อขึ้นกลางจอ + ปรับซูมให้พอดีขนาดพื้นที่อัตโนมัติ (เฉพาะ tag-mode)
cam=battle-map: มุมมองสไตล์ RTS (เอียงเบาๆ ไม่หมุน) ใช้คู่กับ arrows เพื่อวาดลูกศรเดินทัพหลายเส้นพร้อมกัน แยกสีตามฝ่าย
arrows=ฝ่าย1:RRGGBB:lat,lng:lat,lng;ฝ่าย2:RRGGBB:lat,lng:lat,lng — คั่นแต่ละลูกศรด้วย ; ภายในคั่นด้วย : เป็น ชื่อฝ่าย:สีฮ็กซ์:ต้นทาง:ปลายทาง
transport: plane / car / ship / train / walk — ไอคอนพาหนะวิ่งไปตามเส้นทางตอน cam=fly-to (ดีฟอลต์ไม่มีไอคอนวิ่งเลย ต้องระบุเอง — กันโชว์เครื่องบินผิดยุคในฉากประวัติศาสตร์ก่อนมีเครื่องบิน)
shade: on หรือใส่ตัวเลข (รัศมีเป็น px เช่น 250) — มืดรอบข้าง เหลือจุดสนใจสว่างแบบสปอตไลต์
hide: pin,boundary,arrow,timeline,topbar,brand — ซ่อนอย่างใดอย่างหนึ่งเฉพาะฉากนั้น (คั่นด้วย ,)
landfill: flag — เติมสีไฮไลต์เขตแดนเป็นลายธงชาติจริงแทนสีทึบ (ใช้คู่กับ highlight)
reveal: fade / wipe / split / circular / diamond — ลักษณะการเผยพื้นที่ไฮไลต์ (ดีฟอลต์ fade)
trace: one / two / tworeverse / four — จำนวนจุดเริ่มลากเส้นขอบเขตพร้อมกัน (ดีฟอลต์ one)
warmorph: RRGGBB:lat1,lng1:lat2,lng2 — พื้นที่ฝั่งขวาของเส้น (ยืนที่จุด1 หันไปจุด2) เปลี่ยนสีเป็นฝ่ายชนะทีละนิด ใช้คู่กับ highlight
mainland: on — ตัดเกาะ/ดินแดนไกลออกไปทิ้งตอนคำนวณกรอบกล้อง (ใช้คู่กับ highlight)
labelfont / labelsize / labelweight: ปรับฟอนต์/ขนาด/น้ำหนักตัวอักษรป้ายชื่อหมุดเฉพาะฉากนั้น
caption / captionpos: caption=ข้อความ | captionpos=top/center/bottom — ข้อความลอยกลางจอ ไม่ผูกกับหมุด (ทำหัวข้อ/คำโปรย)
geophoto: url:lat,lng — ปักรูปจริง (จากที่อัปโหลดไว้) ตามพิกัดจริงบนแผนที่
draw / drawcolor: draw=lat,lng;lat,lng;... — ลากเส้นอิสระตามพิกัดที่พิมพ์เอง (ขีดเส้นทาง/วงล้อม) สีกำหนดด้วย drawcolor=RRGGBB
persist: persist=2 — ให้เขตแดนที่ไฮไลต์ไว้ค้างอยู่ต่ออีก N ฉากถัดไป แม้ฉากถัดไปไม่ได้ตั้ง highlight
focus: focus=on — ทำพื้นหลังทั้งจอเป็นขาวดำ เหลือแค่เขตที่ไฮไลต์เป็นสีสดจัด (ต้องมี highlight ด้วย)
highlightcolor: highlightcolor=RRGGBB — เปลี่ยนสีไฮไลต์เขตแดนจากเหลืองทองดีฟอลต์ (ใช้คู่กับ highlight)
badge: badge=flag:us:lat,lng:สหรัฐอเมริกา หรือ badge=icon:🏛️:lat,lng:ป้ายชื่อ — ไอคอนวงกลม(ธงชาติ/อีโมจิ)+ป้ายชื่อปักตามพิกัด
callout: callout=url:lat,lng:ป้ายชื่อ — วงแหวนชี้จุดพิกัดจริง พร้อมเส้นโยงไปกล่องรูปแทรกมุมขวาบน (ใช้ url รูปที่อัปโหลดไว้)
route: route=road — เส้นทางระหว่างฉากนี้กับฉากก่อนหน้าวิ่งตามถนนจริง (ผ่าน OSRM) แทนเส้นโค้งจำลอง เหมาะกับฉากท่องเที่ยว/เดินทางในพื้นที่เดียวกัน
follow: follow=on — กล้องติดตามไอคอนพาหนะไปตลอดเส้นทาง (ใช้กับ cam=fly-to) แทนการซูมเห็นเส้นทางทั้งหมดนิ่งๆ
speed: speed=80 — ความเร็วเดินทางจริง (กม./ชม.) เอนจิ้นคำนวณเวลาที่ไอคอนใช้วิ่งจากระยะทางจริง/ความเร็วแทนการเดาความยาวฉากเอง (ใช้กับ cam=fly-to)
insert: ข้อความหรือ url รูป ใช้กับ cut-to-insert / insert-overlay
ในช่องสคริปต์: แบ่งซับไตเติลหลายช่วงในฉากเดียวด้วย ;; (ห้ามใช้ |) — แต่ละช่วงพากย์เสียงจริงแยกกันแล้วต่อเรียงกัน (ต้องรัน server.py ไม่ใช่ http.server เฉยๆ)
