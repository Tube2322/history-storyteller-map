วางสคริปต์ฉากของคุณ แล้วกด "นำเข้าสคริปต์" เพื่อเริ่มดูตัวอย่าง

นำเข้าสคริปต์ซีน

🧭 สร้างฉากง่ายๆ (จากจุด A ไป B) — ไม่ต้องพิมพ์ tag เอง (กด "แก้ไข" ที่การ์ดฉากในแท็บ "เขียนสคริปต์" เพื่อแก้ฉากที่สร้างไว้ก่อนหน้าได้)

🔍 ค้นข้อมูลจริงจาก Wikidata (ฟรี ไม่ต้องมีคีย์)

หาพิกัด/ปี/คำอธิบายจริงของเหตุการณ์ประวัติศาสตร์ก่อนพิมพ์ลงสคริปต์เอง — พิมพ์ชื่อเหตุการณ์ให้เจาะจง (ภาษาอังกฤษแม่นกว่ามาก) เช่น Attack on Pearl Harbor ไม่ใช่ Pearl Harbor เฉยๆ (จะได้หนังปี 2001 แทน) หรือ Battle of Midway ไม่ใช่ Midway เฉยๆ (จะได้เมืองในรัฐ Kentucky แทนเกาะมิดเวย์) — ระบบไม่เชื่อมต่ออัตโนมัติให้เด็ดขาด เพราะ Wikidata ค้นด้วยข้อความจับ entity ผิดได้ง่าย ต้องอ่านคำอธิบายที่โชว์แล้วเช็กเองก่อนว่าใช่เหตุการณ์ที่ต้องการจริงๆ ก่อนคัดลอกไปใช้

🔊 ค้นเสียงประกอบ/SFX จาก Wikimedia Commons (ฟรี ไม่ต้องมีคีย์)

ค้นไฟล์เสียงจริง (เสียงไซเรน/ระเบิด/ฝูงชน/คำปราศรัยประวัติศาสตร์ ฯลฯ) พิมพ์ภาษาอังกฤษแม่นกว่า เช่น air raid siren — เจอแล้วกดคัดลอกลิงก์ไปวางในคีย์ audiourl= ของฉากนั้น (ข้าม TTS ใช้ไฟล์นี้แทนเสียงพากย์ทั้งฉาก)

🎬 ค้นวิดีโอประวัติศาสตร์จาก Internet Archive (ฟรี ไม่ต้องมีคีย์)

คลังฟิล์ม/newsreel สาธารณสมบัติจริง พิมพ์ภาษาอังกฤษเจาะจงเหตุการณ์ เช่น pearl harbor newsreel 1941 — กด "ดึงลิงก์เล่นได้" แล้วเช็กชื่อ/คำอธิบายให้ตรงก่อนคัดลอกไปวางในคีย์ videourl= (ไฟล์อาจใหญ่โหลดช้า ลองเล่นดูก่อนใช้จริงเสมอ)

วิธีเขียนสคริปต์ + รายการ tag ทั้งหมด (แตะเพื่อดู)

ข้อกำหนดของสคริปต์ (อ่านก่อนพิมพ์):
• ต้องมี 2 อย่างเสมอ: place (ชื่อสถานที่) + script (บทพากย์) — ขาดอันใดอันหนึ่ง ฉากนั้นจะถูกข้ามเงียบๆ (ไม่ error ให้เห็น ต้องเช็กเองว่าจำนวนฉากในเส้นเวลาตรงกับที่พิมพ์)
• Auto Director — cam ไม่ใส่ก็ได้: ใส่เอง (ต้องสะกดตรงตามรายการด้านล่าง) = ใช้ตามนั้นเสมอ ไม่ใส่หรือสะกดผิด = ระบบเดามุมกล้องให้เองจากคำในบทพากย์ (เจอคำเกี่ยวกับการรบ/รุกราน/สงคราม → battle-map, เจอคำเกี่ยวกับการเดินทาง/เคลื่อนทัพ → fly-to, เดาไม่ออก → establishing) เดาแค่มุมกล้องเท่านั้น ไม่สร้าง arrows/highlight/insert ให้เองเด็ดขาด ดูได้ในการ์ดพรีวิวฉาก (ป้าย "cam:... (auto, Director)" ถ้าเป็นการเดา) และแถวสรุป "MAP + ..." บอกว่าฉากนั้นมีองค์ประกอบภาพอะไรบ้างจริงๆ
• Visual Rhythm (Debug Mode): เปิดโหมดตรวจสอบแล้วจะเตือนถ้าฉากติดกันตั้งแต่ 4 ฉากขึ้นไปใช้มุมกล้องเดิมซ้ำ หรือมีรูป/วิดีโอประกอบทุกฉากติดกันจนอาจดูเหมือน slideshow — เตือนเฉยๆ ไม่ได้แก้ฉากให้เอง
• ห้ามใช้ | ในเนื้อหา (ชื่อสถานที่/บทพากย์/ค่าใดๆ) เพราะ | คือตัวคั่น tag — ถ้าต้องแบ่งบทพากย์เป็นหลายช่วงให้ใช้ ;; แทน
• แต่ละบรรทัด = 1 ฉาก, คั่นแต่ละ tag ในบรรทัดด้วย |, ในหนึ่ง tag คั่นชื่อคีย์กับค่าด้วย =
• ชื่อคีย์ (เช่น place, cam) ใช้ได้เฉพาะตัวอักษรไทย/อังกฤษเท่านั้น ห้ามมีตัวเลข ขีด หรือช่องว่างปนในชื่อคีย์
• พิกัด (latlng, จุดใน arrows/warmorph/draw/geophoto) ต้องเป็น lat,lng คั่นด้วย , เท่านั้น เรียง lat ก่อน lng เสมอ
• พิมพ์เฉพาะคีย์ที่จำเป็นก็พอ ที่เหลือ default ให้อัตโนมัติ — คีย์ที่พิมพ์ผิด/ไม่มีในระบบจะถูกข้ามเงียบๆเช่นกัน (ไม่ error) ดังนั้นถ้าตั้งค่าแล้วไม่มีผล ให้เช็กตัวสะกดคีย์ก่อน
• แผนกล้อง/ไอคอน/เอฟเฟกต์ ต้องสะกดตรงกับรายการที่กำหนดไว้เป๊ะ (ตัวเล็กหมดทุกตัว) — สะกดผิดจะถูกใช้ค่า default แทนเงียบๆ

แบบ tag (ยืดหยุ่น เรียงลำดับไหนก็ได้ ไม่ใส่คีย์ไหนก็ default):
place=... | latlng=lat,lng | cam=... | script=... | sec=... | icon=... | effect=... | tilt=... | bearing=... | highlight=... | insert=...
ใส่แค่บางคีย์ก็ได้ เช่น place=สุโขทัย | cam=fly-to | script=... | tilt=40 | bearing=200

แบบ column เดิม (เรียงตำแหน่งตายตัว):
สถานที่ | lat,lng | แผนกล้อง | สคริปต์เสียง | วินาที | ไอคอน | เอฟเฟกต์ | insert

แผนกล้อง: establishing / fly-to / push-in / zoom-out / orbit / cut-to-insert / insert-overlay / battle-map
ไอคอน: city / castle / ship / battle / flag / mountain / camp / temple / tomb / crown (ไม่ใส่ = 📍)
เอฟเฟกต์: storm / fire / battle / ghost / fog / candle / lightning / ruins / crown / none — สติ๊กเกอร์อนิเมชันปักบนพิกัด
tilt: 0-60 (องศาเอียงกล้อง 3D) · bearing: 0-360 (ทิศเริ่มช็อต ไม่หมุนต่อเนื่อง) — ใช้ได้เฉพาะ tag-mode
highlight: country / province / place / none — ไฮไลต์เขตแดนจริงจาก OpenStreetMap ตามพิกัด พร้อมป้ายชื่อขึ้นกลางจอ + ปรับซูมให้พอดีขนาดพื้นที่อัตโนมัติ (เฉพาะ tag-mode)
cam=battle-map: มุมมองสไตล์ RTS (เอียงเบาๆ ไม่หมุน) ใช้คู่กับ arrows เพื่อวาดลูกศรเดินทัพหลายเส้นพร้อมกัน แยกสีตามฝ่าย
arrows=ฝ่าย1:RRGGBB:lat,lng:lat,lng;ฝ่าย2:RRGGBB:lat,lng:lat,lng — คั่นแต่ละลูกศรด้วย ; ภายในคั่นด้วย : เป็น ชื่อฝ่าย:สีฮ็กซ์:ต้นทาง:ปลายทาง
transport: plane / car / ship / train / walk — ไอคอนพาหนะวิ่งไปตามเส้นทางตอน cam=fly-to (ดีฟอลต์ไม่มีไอคอนวิ่งเลย ต้องระบุเอง — กันโชว์เครื่องบินผิดยุคในฉากประวัติศาสตร์ก่อนมีเครื่องบิน)
shade: on หรือใส่ตัวเลข (รัศมีเป็น px เช่น 250) — มืดรอบข้าง เหลือจุดสนใจสว่างแบบสปอตไลต์
hide: pin,boundary,arrow,timeline,topbar,brand — ซ่อนอย่างใดอย่างหนึ่งเฉพาะฉากนั้น (คั่นด้วย ,)
landfill: flag — เติมสีไฮไลต์เขตแดนเป็นลายธงชาติจริงแทนสีทึบ (ใช้คู่กับ highlight)
reveal: fade / wipe / split / circular / diamond — ลักษณะการเผยพื้นที่ไฮไลต์ (ดีฟอลต์ fade)
trace: one / two / tworeverse / four — จำนวนจุดเริ่มลากเส้นขอบเขตพร้อมกัน (ดีฟอลต์ one)
warmorph: RRGGBB:lat1,lng1:lat2,lng2 — พื้นที่ฝั่งขวาของเส้น (ยืนที่จุด1 หันไปจุด2) เปลี่ยนสีเป็นฝ่ายชนะทีละนิด ใช้คู่กับ highlight
mainland: on — ตัดเกาะ/ดินแดนไกลออกไปทิ้งตอนคำนวณกรอบกล้อง (ใช้คู่กับ highlight)
labelfont / labelsize / labelweight: ปรับฟอนต์/ขนาด/น้ำหนักตัวอักษรป้ายชื่อหมุดเฉพาะฉากนั้น
photosize: 120 — ปรับขนาด (px) การ์ดภาพ geophoto=/Smart Import/วิดีโอปักพิกัดของฉากนั้น (สี่เหลี่ยมจัตุรัส) ไม่ใส่ = ดีฟอลต์ 84px เดิม
videourl / audiourl: วางลิงก์วิดีโอ/เสียงตรงๆ (เช่นจากเครื่องมือค้น Internet Archive/Wikimedia Commons Audio ด้านล่างในแท็บ "สร้างฉากง่ายๆ") — videourl= ปักการ์ดวิดีโอที่ฉากเหมือน Smart Import, audiourl= ข้าม TTS ใช้ไฟล์นี้พากย์แทนทั้งฉาก
caption / captionpos: caption=ข้อความ | captionpos=top/center/bottom — ข้อความลอยกลางจอ ไม่ผูกกับหมุด (ทำหัวข้อ/คำโปรย)
geophoto: url:lat,lng หรือ url:lat,lng:ป้ายชื่อ — ปักรูปจริง (จากที่อัปโหลดไว้/ค้นอัตโนมัติ) ตามพิกัดจริงบนแผนที่ ใส่ป้ายชื่อเพิ่มได้
draw / drawcolor: draw=lat,lng;lat,lng;... — ลากเส้นอิสระตามพิกัดที่พิมพ์เอง (ขีดเส้นทาง/วงล้อม) สีกำหนดด้วย drawcolor=RRGGBB
persist: persist=2 — ให้เขตแดนที่ไฮไลต์ไว้ค้างอยู่ต่ออีก N ฉากถัดไป แม้ฉากถัดไปไม่ได้ตั้ง highlight
focus: focus=on — ทำพื้นหลังทั้งจอเป็นขาวดำ เหลือแค่เขตที่ไฮไลต์เป็นสีสดจัด (ต้องมี highlight ด้วย)
highlightcolor: highlightcolor=RRGGBB — เปลี่ยนสีไฮไลต์เขตแดนจากเหลืองทองดีฟอลต์ (ใช้คู่กับ highlight)
badge: badge=flag:us:lat,lng:สหรัฐอเมริกา หรือ badge=icon:🏛️:lat,lng:ป้ายชื่อ — ไอคอนวงกลม(ธงชาติ/อีโมจิ)+ป้ายชื่อปักตามพิกัด
callout: callout=url:lat,lng:ป้ายชื่อ — วงแหวนชี้จุดพิกัดจริง พร้อมเส้นโยงไปกล่องรูปแทรกมุมขวาบน (ใช้ url รูปที่อัปโหลดไว้)
route: route=road — เส้นทางระหว่างฉากนี้กับฉากก่อนหน้าวิ่งตามถนนจริง (ผ่าน OSRM) แทนเส้นโค้งจำลอง เหมาะกับฉากท่องเที่ยว/เดินทางในพื้นที่เดียวกัน
follow: follow=on — กล้องติดตามไอคอนพาหนะไปตลอดเส้นทาง (ใช้กับ cam=fly-to) แทนการซูมเห็นเส้นทางทั้งหมดนิ่งๆ
speed: speed=80 — ความเร็วเดินทางจริง (กม./ชม.) เอนจิ้นคำนวณเวลาที่ไอคอนใช้วิ่งจากระยะทางจริง/ความเร็วแทนการเดาความยาวฉากเอง (ใช้กับ cam=fly-to)
style: style=doc-classic — พรีเซ็ตลุกเล่นการนำเสนอ (30 แบบ 5 หมวด: สารคดี/วล็อก/ข่าว/มหากาพย์/ผี) ตั้งเอฟเฟกต์+สีไฮไลต์+สปอตไลต์+ลักษณะเผยพื้นที่+โทนพากย์เสียงให้อัตโนมัติ (ทับเฉพาะค่าที่ยังไม่ได้ตั้งเองใน tag อื่น) — ดูรายชื่อทั้งหมดในดรอปดาวน์ "สร้างฉากง่ายๆ" ด้านบน

Story System (ไม่ใส่ก็ได้ทั้งหมด — engine เดาให้เองจากเนื้อหาสคริปต์ ถ้าใส่เองจะทับค่าเดาเสมอ):
narrative: hook / context / setup / development / escalation / conflict / reveal / turningpoint / climax / consequence / resolution / conclusion — หน้าที่ของฉากนี้ในเรื่อง (ไม่ใส่ = auto ให้ engine เดาจากเนื้อหา ใช้แสดงในพรีวิวเท่านั้น ไม่บังคับพฤติกรรมกล้อง/เอฟเฟกต์)
beat: hook / question / setup / reveal / escalation / conflict / twist / turningpoint / payoff — จังหวะสำคัญของการเล่าเรื่อง (ไม่ใส่ = auto) — beat reveal/twist/turningpoint/payoff เสริมเวลาพักก่อนตัดฉากถัดไปให้อัตโนมัติ
importance: low / medium / high / critical — คุมแค่ "จังหวะ" ไม่เพิ่ม effect/reveal/กล้องใหม่ให้เอง (ไม่ใส่ = เดาจากเนื้อหา ไม่มั่นใจ = medium เท่าเดิมทุกอย่าง) — critical กล้องขยับช้าลง+พักก่อนตัดฉากนานขึ้น (ให้เวลาคนดูอ่าน/ซึมซับ), low กล้องขยับไวขึ้น
mood: calm / curious / mysterious / tension / fear / tragic / epic / hope / shock — คุมจังหวะกล้อง+โทนพากย์เสียง (rate/pitch) เท่านั้น (ไม่ใส่ = auto เดาจากเนื้อหา ไม่มั่นใจ = ใช้โทนของ style ถ้ามี ไม่งั้นใช้ค่าเสียงกลางปกติ) — ใส่เองจะทับโทนของ style เสมอ

Camera System (ทั้งหมด optional — cam เดิม 8 แบบยังทำงานเหมือนเดิมทุกตัวถ้าไม่ใส่คีย์พวกนี้):
shot: establishing / wide / medium / close / detail / insert — ระยะภาพ ปรับซูมจาก baseline เดิมของ cam นั้นๆ (ไม่ใส่ = ใช้ baseline เดิมเป๊ะ)
cameraaction: static / gentle / cinematic / dynamic / urgent / tracking / reveal / drift — ลักษณะการเคลื่อนกล้อง คูณเข้ากับความเร็วกล้อง (ไม่ใส่ = ไม่คูณ)
focuspoint: focuspoint=lat,lng — จุดที่กล้องเล็ง แยกจากพิกัดหลักของฉาก (latlng ยังเป็นพิกัดของหมุด/ไฮไลต์เหมือนเดิมทุกจุด ไม่กระทบ)
motion: static / slow / normal / fast / accelerate / decelerate — ความเร็วกล้อง คูณเข้ากับ cameraaction (accelerate/decelerate โดยนัยเซ็ต motioncurve ให้ด้วยถ้ายังไม่ได้ตั้งเอง)
motioncurve: linear / ease-in / ease-out / ease-in-out — รูปแบบเร่ง/ชะลอของกล้อง (ไม่ใส่ = ใช้เส้นโค้งเดิมของระบบ)
Geographic Camera Continuity: ถ้าฉากนี้ไม่ได้ตั้ง tilt=/bearing= เอง และพิกัดอยู่ใกล้ฉากก่อนหน้า (≲60กม.) กล้องจะสืบทอดมุมเอียง/ทิศจากฉากก่อนแทนการรีเซ็ตกลับ 0 ทุกครั้ง

Scene Connection System (ทั้งหมด optional — เชื่อมโยงกัน ไม่ใส่ = พฤติกรรมเดิมทุกจุด):
continuity: on / off — ทับ heuristic ระยะทางของ Geographic Camera Continuity เสมอ (on = สืบทอดมุม/ซูมกล้องไม่ว่าไกลแค่ไหน, off = รีเซ็ตกล้องทุกครั้งแม้ใกล้ฉากก่อนหน้า) ไม่ใส่ = ใช้ heuristic ระยะทางเดิม
visualbridge: on — ฉากที่ไม่ใช่ fly-to ถ้ากระโดดไกลจากฉากก่อนหน้ามาก จะซูมออกเห็นทั้งสองจุดสั้นๆก่อนแล้วค่อยเข้ากล้องจริง แทนการตัดตรงแบบรีเซ็ตแผนที่ (เช่น เบอร์ลิน → ฝรั่งเศส)
transition: cut / fade / dissolve / match / travel / morph / reveal / whip / none — ลูกเล่นเปลี่ยนฉาก (แฟลชสั้นๆกลบรอยตัด) ไม่ใส่ = engine เดาเอง (ฉากแผนที่ต่อฉากแผนที่ปกติ = ไม่มีอะไรเลย, ตัดเข้า/ออกภาพแทรกจริง = dissolve นุ่มๆ) — importance สูงลดความหวือหวาของ transition ให้อัตโนมัติ
returnmap: on — หลัง insert ภาพจริงจบ ฉากที่กลับมาเป็นแผนที่จะสืบทอดตำแหน่ง/ซูม/มุมกล้องจาก "ฉากแผนที่จริงล่าสุดก่อนตัดเข้า insert" แทนเริ่มใหม่ (ข้ามระยะทาง ใช้ได้แม้ insert อยู่คนละพิกัด)

mapmode: location / journey / movement / expansion / retreat / encirclement / invasion / territorial-change / comparison / before-after / timeline — ป้ายกำกับ "โหมดแผนที่" ของฉากนี้ (metadata เท่านั้น ไม่เพิ่ม arrows/highlight/draw/warmorph/route ให้เองเด็ดขาด) ไม่ใส่ = engine เดาจากคำในสคริปต์ก่อน แล้วดูจากองค์ประกอบที่มีอยู่แล้วในฉาก (arrows→movement, warmorph→territorial-change, route=road→journey, draw→encirclement) เดาไม่ออกเลย = location
insertmode: full / overlay / picture-in-picture / split / background — เลย์เอาต์กล่อง insert ไม่ใส่ = ดีฟอลต์ตาม cam เดิม (cut-to-insert→full, insert-overlay→picture-in-picture) เหมือนเดิมทุกจุด
inserttransition: cut / fade / dissolve / match / slide / flash — เปลี่ยนฉากตอนเข้า/ออก insert เท่านั้น ทับดีฟอลต์ dissolve อัตโนมัติ (แพ้ transition= ทั่วไปถ้าตั้งไว้ด้วย)
evidence: photo / painting / document / newspaper / portrait / artifact / archive / map — ป้ายบอกประเภทหลักฐานบนกล่อง insert (ห้ามสร้าง url เอง ต้องมี insert= จริงถึงจะโชว์)
insert: ข้อความหรือ url รูป ใช้กับ cut-to-insert / insert-overlay — มีระบบป้องกันการบังอัตโนมัติ (กล่อง overlay/PiP สลับฝั่งเองถ้าฉากมี callout=/badge= ด้วย)

Documentary Editor Intelligence (ทั้งหมด optional — คูณ/เสริมเข้ากับจังหวะเดิม ไม่ใส่ = พฤติกรรมเดิม 100%):
pace: very-slow / slow / normal / fast / very-fast — ความไวของกล้อง ไม่ใส่ = normal (climax เดาเป็น fast ให้อัตโนมัติ)
pacing: build / accelerate / decelerate / release / pause — จังหวะรวมของฉาก (release/pause เสริมเวลาพักก่อนตัดฉากถัดไปให้อัตโนมัติ) — หลัง narrative=climax ฉากถัดไปจะได้ pacing=release อัตโนมัติถ้ายังไม่ได้ตั้งเอง
density: minimal / low / medium / high — ความหนาแน่นข้อมูล ดีฟอลต์ medium; high ลดความเร็วกล้อง+เพิ่มเวลาอ่าน+ลด effect ที่มาจาก style preset (ไม่แตะ effect= ที่พิมพ์เอง)
attention: primary / secondary / background — ความเด่นของฉาก ดีฟอลต์ primary; background ลดความเด่นซับไตเติล+ลด effect ที่มาจาก style preset
emphasis: none / subtle / medium / strong — คูณเข้ากับความเข้มของ transition ที่ resolve ไว้แล้ว (ไม่สร้าง transition เองจากศูนย์) ดีฟอลต์ medium (ไม่เปลี่ยนอะไร) — beat=twist/turningpoint เดาเป็น subtle ให้อัตโนมัติ
intensity: low / medium / high — ความเข้มข้นของกล้อง ดีฟอลต์ medium (climax เดาเป็น high อัตโนมัติ)
composition: auto / left / right / center / top / bottom — ตำแหน่งกล่อง insert (left/right ทับ heuristic ป้องกันการบังอัตโนมัติได้)
Anti-Overediting: ฉากที่มี insert+caption+arrows+highlight+effect พร้อมกันตั้งแต่ 4 อย่างขึ้นไป จะลด effect ที่มาจาก style preset (ไม่ใช่ที่พิมพ์เอง) ให้อัตโนมัติ กันฉากรกเกินไป

Smooth Geographic Navigation (ทั้งหมด optional — ดีฟอลต์ใหม่: ฉากไกลมากซูมออกเผยบริบทก่อนอัตโนมัติ กันภาพกระโดด):
navigation: auto / smooth / direct — ดีฟอลต์ auto (เลือกวิธีเคลื่อนกล้องตามระยะทางจริง) smooth บังคับซูมออก-เดินทาง-ซูมเข้าเสมอ direct บังคับตัดตรงเสมอ (แทนที่ default เดิม "กระโดดตรง" ด้วยเหตุผลกันภาพกระตุก/เวียนหัว — visualbridge=on/off เดิมที่ตั้งเองยัง priority สูงสุดเหมือนเดิม)
travelmode: local / regional / global — ไม่ใส่ = คำนวณจากระยะทางจริงระหว่างฉากก่อนหน้ากับฉากนี้ (local <150กม. ไม่ซูมออก, regional <1500กม. ซูมออกปานกลาง, global ไกลกว่านั้นซูมออกเผยบริบทกว้างขึ้นแต่ไม่เกินจำเป็น)

Full Scene Preload: กด "เล่น" (ไม่ใช่ตอนดูตัวอย่างทีละฉาก) เตรียมเสียงพากย์+รูปประกอบ (geophoto/callout/badge ธง/insert รูป) ทุกฉากในสคริปต์ให้เสร็จก่อนเริ่มเล่นจริงเสมอ — แก้สคริปต์แค่บางฉาก เสียงที่ไม่เปลี่ยนจะไม่ generate ซ้ำ (cache ตามเนื้อหาข้อความจริง)

โหมดตรวจสอบ (Debug): เปิดได้จากช่อง "โหมดตรวจสอบ" ด้านล่าง — แสดงรายการปัญหาที่เจอตอนแปลงสคริปต์ล่าสุด (คีย์ไม่รู้จัก/พิกัดผิด/ขาด place-cam-script ฯลฯ) โดยไม่กระทบการแสดงผลปกติเลย คีย์ผิด/ไม่รู้จักถูกข้ามเงียบๆเสมอไม่ว่าจะเปิดโหมดนี้หรือไม่
ในช่องสคริปต์: แบ่งซับไตเติลหลายช่วงในฉากเดียวด้วย ;; (ห้ามใช้ |) — แต่ละช่วงพากย์เสียงจริงแยกกันแล้วต่อเรียงกัน (ต้องรัน server.py ไม่ใช่ http.server เฉยๆ)

🗺️ MAP-FIRST — แผนที่เป็นพระเอก ใช้ภาพ/วิดีโอน้อยที่สุด (สไตล์สารคดี ไม่ใช่ slideshow):
เอ็นจินนี้ไม่มี "AI ตัดสินใจ visual ให้อัตโนมัติ" แต่มี tag ที่ทำสิ่งเดียวกันได้ครบถ้าเขียนสคริปต์ตามแพทเทิร์นนี้:
• ฉากส่วนใหญ่ควรเป็น cam=establishing/fly-to/push-in/orbit/battle-map เฉยๆ (แผนที่ล้วน ไม่มี insert) — นี่คือ "MAP ONLY" ค่าเริ่มต้นของทุกฉาก
• ต้องการ "บอกพื้นที่/แนวรบ": ใช้ cam=battle-map + arrows= (ลูกศรแนวรุก) หรือ highlight= (ไฮไลต์เขตแดนจริง) เฉพาะฉากที่กำลังพูดถึงการเคลื่อนที่/แนวรบเท่านั้น ฉากอื่นไม่ต้องมี
• ต้องการ "โชว์ภาพประกอบเล็กๆ ไม่เต็มจอ": ใช้ cam=insert-overlay (ไม่ใช่ cut-to-insert ซึ่งเต็มจอ) + insertmode=picture-in-picture — ได้กรอบเล็กมุมจอ แผนที่ยังโชว์อยู่ข้างหลัง ตรงกับ "SMALL IMAGE INSERT" — หรือใช้ geophoto=/Smart Import (image=) ที่เป็นการ์ดเล็กปักพิกัดอยู่แล้วโดยดีฟอลต์ ไม่เต็มจอเช่นกัน
• ต้องการ "ตัดไปภาพ/วิดีโอเต็มจอชั่วครู่แล้วกลับแผนที่" (EXPLAIN→SHOW→RETURN): แทรกฉากสั้นๆ 1 ฉาก cam=cut-to-insert ระหว่างฉากแผนที่ 2 ฉาก แล้วฉากแผนที่ที่กลับมาใส่ returnmap=on — กล้องจะสืบทอดตำแหน่ง/ซูมจากฉากแผนที่ก่อนหน้า ไม่กระโดดเริ่มใหม่
• ไม่อยากให้ฉากรกด้วย effect ตกแต่ง: ใส่ density=low หรือ minimal (ลดความเร็วกล้อง+ลด effect จาก style preset อัตโนมัติ) — เส้น/ลูกศร/insert ที่พิมพ์เองยังโชว์เสมอ (เอ็นจินไม่ลบสิ่งที่สั่งเองตรงๆ)
• กด "🗺️ โหลดตัวอย่าง MAP-FIRST" ด้านบนปุ่ม "แปลงเป็นฉาก" เพื่อโหลดสคริปต์ตัวอย่างที่ใช้แพทเทิร์นนี้ครบ (MAP → แนวรบ → INSERT เล็ก → กลับ MAP) มาแก้ไขต่อได้เลย

🎬 SMART IMPORT — จับคู่รูป/วิดีโอ/เสียงกับฉากอัตโนมัติ

กด "แปลงเป็นฉาก" ด้านบนก่อน 1 ครั้ง แล้วลากสื่อทั้งหมดมาวางที่นี่ทีเดียว — ไม่ต้อง rename ไฟล์ ไม่ต้องลากทีละฉาก ถ้าในสคริปต์มี image=01 / video=01 / audio=01 ระบบจับคู่ตามเลขนั้นก่อนเป็นอันดับแรก (มั่นใจ 100%) ฉากที่ไม่ได้ระบุเลขจะได้ไฟล์ที่เหลือไปเรียงตามลำดับอัพโหลดแทน (มั่นใจ 75%) — ไม่ใส่ image=/video=/audio= เลยสักฉากก็ยังใช้ได้ปกติ (ทำงานเหมือนเดิม 100%)

ทำงานตอนกด "เล่น" เท่านั้น (ส่วนของ Full Scene Preload) — ข้ามฉากที่มีรูป/วิดีโอจาก Smart Import หรือ geophoto= อยู่แล้ว และข้ามฉาก cut-to-insert/insert-overlay (ต้องใส่ insert= เอง) หาไม่เจอ = ไม่มีรูปเหมือนเดิม ไม่ error ดีฟอลต์ปิด (ต้องเปิดเอง)

เลือกได้เป็นรายฉากด้วย tag autoimage=on หรือ autoimage=off — ทับตัวเลือกรวมด้านบนเสมอ เช่น เปิด toggle รวมไว้แต่บางฉากอยากใส่รูปเองแน่ๆ ไม่ให้ไปดึงทับ ใส่ autoimage=off ที่ฉากนั้น หรือปิด toggle รวมไว้แต่อยากให้ดึงอัตโนมัติเฉพาะบางฉาก ใส่ autoimage=on ที่ฉากนั้น

ดึงภาพให้ตรงยุคเหตุการณ์: ค้นแค่ชื่อสถานที่เฉยๆ มักได้รูปปัจจุบัน/นักท่องเที่ยว (เช่น "เพิร์ลฮาร์เบอร์" ได้รูปพิพิธภัณฑ์ปี 2013) ระบบจึงเดา "ปี" จากตัวเลขปี ค.ศ. หรือ พ.ศ. ที่เจอในบทพากย์ฉากนั้นให้เองก่อน (เช่นมีคำว่า "1941" หรือ "พ.ศ. 2484" ในสคริปต์ จะค้นเป็น "ชื่อสถานที่ 1941" ให้อัตโนมัติ ได้ภาพยุคเหตุการณ์จริงแม่นขึ้นมาก) ถ้าอยากระบุปีเองตรงๆ ไม่ต้องพึ่งการเดา ใส่ tag year=1941 ที่ฉากนั้นได้เลย (ทับการเดาจากบทพากย์เสมอ)
