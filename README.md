# แผนที่เป็นเวทีของเหตุการณ์ — History Storyteller Map

เอนจิ้นเล่าเรื่องประวัติศาสตร์บนแผนที่: ป้อนสคริปต์ฉากเข้าไป เว็บจัดกล้อง หมุด เส้นทาง และซับไตเติลให้เองตามจังหวะที่กำหนด

## สถานะปัจจุบัน

นี่คือโครง UX/UI (skeleton) — ยังไม่ผูกแผนที่ดาวเทียมจริง (MapLibre GL) และยังไม่เชื่อม edge-tts

สิ่งที่ทำงานได้แล้วในโครงนี้:

- แผงนำเข้าสคริปต์ซีน: วางข้อมูลทีละแถว (สถานที่ | แผนกล้อง | สคริปต์ | วินาที) แล้วแปลงเป็นรายการฉาก
- เส้นเวลาฉากด้านล่าง คลิกเพื่อกระโดดไปแต่ละฉาก สีของแต่ละช่องบอกแผนกล้อง
- แถบบน: ชื่อฉาก/ตอน, ลำดับฉากปัจจุบัน, ป้ายแผนกล้อง, ปุ่มเล่น/หยุด/ก่อนหน้า/ถัดไป
- ซับไตเติลกลางล่างจอ อัพเดทตามฉากที่เลือก
- เวทีแผนที่ (placeholder gradient/grid) ที่เปลี่ยน transform ตามแผนกล้องทั้ง 6 แบบ เพื่อสาธิตจังหวะก่อนต่อ MapLibre จริง

แผนกล้อง 6 แบบ: `establishing` (ภาพเปิดกว้าง) · `fly-to` (กล้องบินเดินทาง) · `push-in` (ซูมเข้าถึงจุดหมาย) · `zoom-out` (ซูมออกเผยภาพรวม) · `orbit` (กล้องหมุนรอบจุดสนใจ) · `cut-to-insert` (ตัดเข้าภาพเต็มจอ)

## เปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ กด "นำเข้าสคริปต์" แล้ววางข้อมูลตัวอย่างที่มีอยู่แล้วในช่อง เพื่อดูตัวอย่างการทำงาน

## ขั้นถัดไป

1. ต่อ MapLibre GL JS จริงแทน placeholder gradient — ผูกพิกัดจริงต่อฉากกับ `flyTo`/`easeTo`
2. ทำตัวแปลงไฟล์ Excel (scene-script-template.xlsx) → JSON ที่เอนจิ้นอ่านได้
3. เชื่อม edge-tts (ต้องมี proxy/backend เพราะเรียกจากเบราว์เซอร์ตรงไม่ได้) เพื่อสร้างเสียงพากย์และวัดความยาวจริงมาแทนค่าประมาณ 5 วินาที/ฉาก
4. แบ่งซับไตเติลหลายช่วงในฉากเดียวตาม timestamp ของเสียงจริง
5. ปุ่ม export วิดีโอ/บันทึกผลลัพธ์
