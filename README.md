# ชีวิตไทย — Thailand Simulation

ต้นแบบเว็บเกม Simulation แบบไม่ต้องติดตั้ง dependency: เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือ deploy เข้า Vercel เป็น static site ได้

## สิ่งที่มีในต้นแบบ

- Dashboard ตัวละครและโลกจำลองชลบุรี
- เวลาของเกมและการอัปเดตสถานะเมื่อกดเดินเวลา
- เส้นทางหางาน, เรียนรู้, เปิดร้านหมูปิ้ง และสร้างความสัมพันธ์กับ NPC
- ข่าวโลก, ตัวชี้วัดเศรษฐกิจ และบันทึก Simulation
- โครง UI สำหรับต่อยอดเป็นระบบ Firebase/Simulation Engine จริง

## เปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรืออัปโหลดไฟล์ทั้งสามไปยัง Vercel

## ขั้นถัดไป

1. ย้าย state ใน `script.js` ไป Firestore
2. เพิ่มระบบล็อกอินและสร้างตัวละคร
3. รัน Simulation Engine ฝั่ง backend ตามช่วงเวลา
4. เพิ่มจังหวัด, NPC และธุรกิจจาก schema ที่ออกแบบไว้
