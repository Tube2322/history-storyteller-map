# แผนที่เป็นเวทีของเหตุการณ์ — History Storyteller Map

เอนจิ้นเล่าเรื่องประวัติศาสตร์บนแผนที่ดาวเทียมจริง: ป้อนสคริปต์ฉาก (พิกัด/แผนกล้อง/บทพากย์) เว็บจัดกล้อง หมุด เส้นทาง เอฟเฟกต์ และเสียงพากย์จริงให้เองตามจังหวะ

## สถานะปัจจุบัน — ครบทั้ง 3 พาทตามแผน

**พาท 1 — UX/UI พื้นฐาน**
- เวทีแนวตั้ง 9:16 (letterbox กลางจอ จำลองฟอร์แมตวิดีโอสั้น)
- แผงนำเข้าสคริปต์ซีน วางข้อมูลทีละแถวหรือไฟล์ Excel
- เส้นเวลาฉากด้านล่าง คลิกกระโดดไปแต่ละฉาก สีบอกแผนกล้อง
- หมุดไอคอน+ป้ายชื่อ, เส้นทางโค้งพร้อมหัวลูกศรระหว่างฉาก
- insert-overlay (กล่องภาพลอย PiP) แยกจาก cut-to-insert (เต็มจอ)
- ป้ายแบรนด์/วอเตอร์มาร์ก ตั้งชื่อย่อ+มุมได้

**พาท 2 — แผนที่จริง**
- MapLibre GL JS บนภาพถ่ายดาวเทียม Esri World Imagery (ฟรี ไม่ต้องใช้คีย์)
- ทุกฉากมีพิกัด lat,lng จริง กล้องเคลื่อนที่ด้วย `flyTo`/`easeTo` ตามแผนกล้อง 7 แบบ (รวม orbit หมุนกล้องจริงด้วย bearing)
- หมุด/เส้นทาง/ลูกศรผูกกับพิกัดจริงผ่าน `maplibregl.Marker` และ geojson line layer
- เอฟเฟกต์เหตุการณ์ (พายุ/ไฟ/รบ) เป็นสติ๊กเกอร์ปักบนพิกัดจริง
- ดาวน์โหลดเทมเพลต Excel และนำเข้าไฟล์ .xlsx ได้ (SheetJS)

**พาท 3 — เสียงพากย์จริง**
- เชื่อม edge-tts ผ่าน `server.py` (proxy ในเครื่อง เพราะเบราว์เซอร์เรียก edge-tts ตรงไม่ได้)
- กดเล่น → พากย์เสียงจริงทีละฉาก ความยาวจริงของเสียงมาแทนค่าประมาณวินาทีที่กรอกไว้ (อัปเดตบนเส้นเวลาสด)
- แบ่งซับไตเติลหลายช่วงในฉากเดียวด้วย `;;` ในช่องสคริปต์ — แต่ละช่วงพากย์แยกกันแล้วเล่นต่อเนื่อง ซับไตเติลสลับตามจริง
- ปุ่ม "บันทึกวิดีโอ" ใช้ `getDisplayMedia` + `MediaRecorder` อัดหน้าจอ (ต้องเลือกแชร์ "แท็บนี้" ตอนเบราว์เซอร์ถาม) ได้ไฟล์ `.webm`

แผนกล้อง 7 แบบ: `establishing` (ภาพเปิดกว้าง) · `fly-to` (กล้องบินเดินทาง) · `push-in` (ซูมเข้าถึงจุดหมาย) · `zoom-out` (ซูมออกเผยภาพรวม) · `orbit` (กล้องหมุนรอบจุดสนใจ) · `cut-to-insert` (ตัดเข้าภาพเต็มจอ) · `insert-overlay` (แทรกภาพลอย PiP)

## เปิดใช้งาน

ต้องรัน `server.py` (ไม่ใช่ `python -m http.server` เฉยๆ) เพราะต้องมี endpoint `/api/tts` สำหรับเสียงพากย์:

```bash
python -m pip install edge-tts
python server.py 5173
```

แล้วเปิด `http://localhost:5173` กด "นำเข้าสคริปต์" → "แปลงเป็นฉาก" (มีข้อมูลตัวอย่างในช่องอยู่แล้ว) แล้วกดเล่น

ถ้าเปิดแค่ `index.html` ตรงๆ หรือรันด้วย `http.server` ธรรมดา แผนที่/หมุด/สคริปต์ยังใช้ได้ปกติ แต่กดเล่นแล้วจะไม่มีเสียง (fetch `/api/tts` จะพัง)

## รูปแบบตารางสคริปต์ซีน

```
สถานที่ | lat,lng | แผนกล้อง | สคริปต์เสียง | วินาที | ไอคอน | เอฟเฟกต์ | insert
```

- ไอคอนหมุด: `city / castle / ship / battle / flag / mountain / camp` (ไม่ใส่ = 📍)
- เอฟเฟกต์: `storm / fire / battle / none`
- insert: ข้อความหรือ url รูป ใช้กับ `cut-to-insert` / `insert-overlay`
- ในช่องสคริปต์ใส่ `;;` เพื่อแบ่งซับไตเติลหลายช่วงในฉากเดียว (ห้ามใช้ `|` เพราะชนกับตัวคั่นคอลัมน์)
- วางเป็นแถวในกล่องข้อความ (คั่นด้วย tab หรือ `|`) หรือดาวน์โหลด/นำเข้าเป็นไฟล์ Excel ก็ได้

2. ปรับกล้อง fly-to ให้ sync กับความยาวเสียงจริงตั้งแต่ต้น (ตอนนี้กล้องเริ่มเคลื่อนที่พร้อมเสียงหลัง fetch เสร็จ ซึ่งมีดีเลย์เล็กน้อยจากการเรียก TTS)
3. รองรับการแปลงไฟล์เสียง/วิดีโอเป็น mp4 (ตอนนี้ export ได้แค่ `.webm` จาก MediaRecorder)
